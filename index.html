鎖定判定：在 100 個連續 reference 週期內，頻率與相位誤差同時低於所設定門檻。「鎖定點模型增益」比較設計採用的 ICP·KVCO 與查表斜率、UP/DN 電流的實際乘積。若控制電壓撞到查表邊界，結果只可視為飽和警告，不可用於 capture range。

1. 狀態向量與時間積分

模擬以 3 個狀態變數描述整個迴路，並用 4 階 Runge–Kutta（RK4）對時間積分：

\[ \mathbf{x}(t) = \begin{bmatrix} V_{\text{ctrl}}(t) \\ V_{C1}(t) \\ \phi_{\text{VCO}}(t) \end{bmatrix}, \qquad \frac{d\mathbf{x}}{dt} = \mathbf{f}(\mathbf{x},t) \]

其中 \(V_{\text{ctrl}}\) 為濾波器輸出（VCO 控制電壓）、\(V_{C1}\) 為 R1–C1 支路節點電壓、\(\phi_{\text{VCO}}\) 為 VCO 累積相位（單位：cycle）。每個 reference 週期 \(T_{\text{ref}}=1/f_{\text{ref}}\) 內切成 sub 個子步，子步長 \(dt=T_{\text{ref}}/\text{sub}\)，逐步以 RK4 更新：

\[ \mathbf{x}_{n+1} = \mathbf{x}_n + \frac{dt}{6}(k_1+2k_2+2k_3+k_4), \quad k_i = \mathbf{f}(\mathbf{x}_n + \cdots) \]

2. PFD 事件與相位座標

參考相位與除頻後 VCO 相位分別為：

\[ \phi_{\text{ref}}(t)=\frac{t}{T_{\text{ref}}}, \qquad \phi_{\text{div}}(t)=\frac{\phi_{\text{VCO}}(t)}{N} \]

顯示與鎖定判定用的相位誤差取兩者之差並 wrap 進 \((-0.5,\,0.5]\) cycle：

\[ e(t) = \text{wrap}\big(\phi_{\text{ref}}(t)-\phi_{\text{div}}(t)\big), \qquad \text{wrap}(x)=\Big(\big((x+0.5)\bmod 1\big)+1\Big)\bmod 1 - 0.5 \]

但 PFD 控制本身不使用此 wrapped 誤差作平均電流，而是由 reference edge \(t=kT_{\text{ref}}\) 與 divider edge \(\phi_{\text{VCO}}/N=m\) 的到達順序更新 UP／DN latch。使用者輸入的「初始相位差 \(\varphi_0\)（°）」透過設定 VCO 相位初始值達成 \(e(0)=\varphi_0/360\)：

\[ \phi_{\text{VCO}}(0) = -N\cdot\frac{\varphi_0}{360^\circ} \]

3. Charge pump pulse（與上方電流失配模型耦合）

reference edge 置位 \(q_{\text{UP}}\)，divider edge 置位 \(q_{\text{DN}}\)。兩者同時為 1 時，經設定的 reset 延遲 \(\tau_{\text{reset}}\) 後清除。因此每段時間內直接積分實際 CP 電流：

\[ I_{\text{cp}}(t)=q_{\text{UP}}(t)I_{\text{UP}}\big(V_{\text{ctrl}}(t)\big)-q_{\text{DN}}(t)I_{\text{DN}}\big(V_{\text{ctrl}}(t)\big) \]

其中 \(I_{\text{UP}}(V)\)、\(I_{\text{DN}}(V)\) 為上方 Virtuoso DC 曲線擬合的電壓相依模型（飽和值 + 靠近電源軌的線性 compliance 衰減）。這保留了 PFD reset、UP/DN 脈衝位置及電流失配造成的殘餘電荷；RK4 只在兩個事件之間積分連續時間狀態。

4. 二階被動迴路濾波器（R1–C1 串聯支路並聯 C2）

對 \(V_{\text{ctrl}}\) 節點做 KCL，並對 R1–C1 支路做 KVL/KCL：

\[ i_{R1}(t)=\frac{V_{\text{ctrl}}(t)-V_{C1}(t)}{R_1} \]

\[ \frac{dV_{\text{ctrl}}}{dt}=\frac{I_{\text{cp}}(t)-i_{R1}(t)}{C_2}, \qquad \frac{dV_{C1}}{dt}=\frac{i_{R1}(t)}{C_1} \]

直覺：\(I_{\text{cp}}\) 注入節點後一部分直接對 \(C_2\) 充放電，另一部分經 \(R_1\) 流入 \(C_1\)；此為標準二階被動 CP-PLL 濾波器拓樸的狀態方程式，與上方「Bode Plot」頁籤所用的 \(Z_{\text{LF}}(s)\) 為同一濾波器的 s-domain／time-domain 對應。

5. VCO：非線性查表相位累加

VCO 不使用線性 \(K_{\text{VCO}}\)，而是即時查詢上方 VCO Tuning Curve（簡化版或精確版）的非線性表 \(f_{\text{VCO}}(V)\)（分段線性插值），並對相位做積分：

\[ \frac{d\phi_{\text{VCO}}}{dt} = f_{\text{VCO}}\big(V_{\text{ctrl}}(t)\big) \quad[\text{cycles/s}] \]

\(V_{\text{ctrl}}\) 在每步積分後會被 clamp 到查表的電壓範圍 \([V_{\min},V_{\max}]\) 內，避免查表外插。

6. 鎖定判定與初始條件

目標頻率 \(f_{\text{target}}=f_{\text{ref}}\cdot N\)。每個 reference 週期取樣一次，同時檢查頻率誤差與相位誤差：

\[ \big|f_{\text{VCO}}(V_{\text{ctrl}})-f_{\text{target}}\big| \le \Delta f_{\text{th}} \quad\text{且}\quad |e(t)\cdot 360^\circ| \le \Delta\varphi_{\text{th}} \]

此條件須連續滿足 100 個 reference 週期（去彈跳，避免暫態穿越門檻造成誤判）才視為鎖定；回傳的「鎖定時間」為該 100 週期視窗起始的時間戳。初始條件為：

\[ V_{\text{ctrl}}(0)=V_{C1}(0)=V_{\text{init}} \ (\Rightarrow i_{R1}(0)=0), \qquad \phi_{\text{VCO}}(0)=-N\cdot\frac{\varphi_0}{360^\circ} \]

此模型忽略 PFD reset 時間、CP 開關非理想（電荷注入、時脈饋通）、元件雜訊與啟動電路動態，僅用於估算鎖定時間量級與參數敏感度趨勢；精確驗證仍需 transistor-level transient。

1. SSPLL 的取樣相位誤差

每個 reference edge \(t=kT_{\text{ref}}\) 對 VCO 相位取樣一次；在 SSPLL 中直接比較 \(N\) 倍 reference 相位和 VCO 相位：

\[ e_k=\operatorname{wrap}\!\left(N\frac{t_k}{T_{\text{ref}}}-\phi_{\text{VCO}}(t_k)\right),\qquad e_k\in[-0.5,0.5)\ \text{cycle} \]

使用者輸入的初始相位差 \(\varphi_0\) 設為 \(\phi_{\text{VCO}}(0)=-\varphi_0/360^\circ\)，故 \(e_0=\varphi_0/360^\circ\)。此為 sub-sampling detector 的行為模型，不是 PFD 的 UP/DN 狀態機。

2. sampled-sine detector 與脈衝電流

取樣值先被保持；Pulser 延遲 \(\tau_d\) 後，偵測器才輸出持續 \(\tau_{\text{pul}}\) 的轉導脈衝，因此不與取樣 aperture 重疊：

\[ I_{\text{pul},k}=2A_{\text{VCO}}g_m\sin(2\pi e_k),\qquad kT_{\text{ref}}+\tau_d\le t<kT_{\text{ref}}+\tau_d+\tau_{\text{pul}} \]

小相位誤差時，平均電流為 \(\overline I\approx \beta_{\text{SS}} e_{\text{rad}}\)，其小訊號偵測器增益正好與設計頁面相同：

\[ \beta_{\text{SS}}=2A_{\text{VCO}}g_m\frac{\tau_{\text{pul}}}{T_{\text{ref}}}\quad[\text{A/rad}] \]

SS core 直接以 \(2A_{\text{VCO}}g_m\sin(2\pi e_k)\) 的有限寬度脈衝驅動濾波器；AVCO、gm 與 \(\tau_{pul}\) 均由設計頁面輸入。可選的 SSCP 輸出非理想模型只加入量測到的 UP／DN branch 最大電流、VCTRL compliance 與 \(I_{offset}=I_{UP,0}-I_{DN,0}\)，不會改變迴路合成、Bode 或 phase-noise 的小訊號參數。

3. 濾波器、VCO 與適用範圍

脈衝電流直接驅動同一個 R1–C1–C2 濾波器；RK4 連續積分 \(dV_{\text{ctrl}}/dt=(I_{\text{pul}}-(V_{\text{ctrl}}-V_{C1})/R_1)/C_2\)、\(dV_{C1}/dt=(V_{\text{ctrl}}-V_{C1})/(R_1C_1)\)，且以非線性 tuning table 計算 \(d\phi_{\text{VCO}}/dt=f_{\text{VCO}}(V_{\text{ctrl}})\)。

論文中的 frequency acquisition 由另一條 FLL 處理：除頻後 VCO 邊緣與 Ref 驅動 3-state PFD；PFD pulse 寬度超過 \(\tau_{\text{DZ}}\) 才讓 FLL charge pump 注入 \(\pm I_{\text{FLL}}\)。預設 \(\tau_{\text{DZ}}=T_{\text{ref}}/2\)，即論文的 \((-\pi,\pi)\) dead zone。FLL 與 SS core 共用此濾波器；近鎖定時 FLL 靜默。

模型保留正弦 detector 與論文所述 FLL dead-zone 的事件行為，但未描述 sampler charge sharing、開關/保持非理想、buffer、spur 或雜訊。請以 post-layout / Virtuoso 的 pulser delay、FLL CP 電流與 dead-zone 實測值校正這三項參數。

相位雜訊模型與 RMS Jitter 數值演算法推導 (Noise & Jitter Theory)

以相位域小訊號模型整理閉迴路轉移函數、各雜訊注入點與 RMS Jitter 數值積分；每一項結果明確區分「直接推導」、「數值後處理」與「物理參數化估算」。

LTI Phase-Domain
直接推導 / Derived

由指定 LTI PLL 與 passive LF 拓樸直接推得，例如 \(Z_{LF}(s)\)、STF/NTF、R1 Johnson-noise transfer。

數值後處理 / Numerical

對 phase-noise PSD 進行線性功率疊加、梯形積分、variance share、cumulative jitter 與 dominance 計算。

物理參數化 / Parametric

Ref / Detector / VCO source PSD 的絕對值需由使用者錨點或模擬校正；頻率斜率依 white/flicker phase-noise 模型建立。

1. 使用者輸入參數至輸出雜訊圖譜之計算資料流 (Data Flow Pipeline)

① 規格與元件合成

由 \(f_{\text{ref}}, f_{\text{VCO}}, K_{\text{VCO}}, I_{\text{CP}}\)（或 \(g_m, A_{\text{VCO}}\)）合成出濾波器 \(R_1, C_1, C_2\)。

② 複數頻域求值

在對數軸採樣 \(f \in [1\text{k}, 100\text{M}]\)，計算各頻率點之 \(T(j2\pi f)\)、\(|H_{\text{cl}}|^2\) 與 \(|H_{\text{vco}}|^2\)。

③ 四路雜訊頻譜塑形

Estimate 模式依據一階 Ref、Detector/CP、LPF \(R_1\)、VCO，以及 CP-PLL Divider 模型配合各 injection-point transfer 進行整形；Cadence 模式則直接讀取 output-referred PNoise contribution，兩種模式最後皆在線性功率域疊加。

④ 梯形數值積分

在指定 \([f_{\text{min}}, f_{\text{max}}]\) 內積分 \(S_\Phi(f)\)，輸出 RMS 抖動 \(\sigma_t\text{ (fs)}\)。

2. 閉迴路雜訊轉移函數 vs PLL 閉迴路增益 (STF vs NTF 單一負回授統一形式)

三者的本質與區別：「閉迴路轉移函數 (Closed-Loop Transfer Function)」是所有負回授閉環路徑的總稱；而 STF (Signal Transfer Function) 與 NTF (Noise Transfer Function) 則是站在不同訊號注入節點時的特定實例。

單一負回授系統的統一形式（Single-Loop Feedback Form）：

\[ H_{\text{closed}}(s) = \frac{\Phi_{\text{out}}(s)}{X(s)} = \frac{G_{\text{forward}}(s)}{1 + T(s)} \]

其中 \(T(s)\) 為繞整個閉迴路一圈的開迴路增益 (Loop Gain)。由於負回授架構閉合，所有雜訊源感受到的分母 \(1 + T(s)\) 完全一致，差異僅在於注入點到輸出端的前向增益路徑 \(G_{\text{forward}}(s)\)：

訊號轉移函數 STF(s)（低通特性）

訊號由參考輸入端注入，前向路徑包含 PFD、LPF 與 VCO：\(G_{\text{forward}}(s) = G(s)\)

\[ \text{STF}(s) = \frac{\Phi_{\text{out}}}{\Phi_{\text{in}}}(s) = \frac{G(s)}{1 + G(s)H(s)} = \frac{G(s)}{1 + T(s)} \]
帶內 \(\omega \ll \omega_c\)

此時 \(|T(s)| \gg 1\)，迴路具有很強的追蹤能力。傳統 CP-PLL 的 absolute phase transfer 為 \(\Phi_{out}/\Phi_{ref} \to N\)。SSPLL 中 \(T_{SS}/(1+T_{SS})\to1\) 則代表內部正規化 sampled-phase loop 的追蹤響應，不可直接解讀為 RF 輸出對 reference phase 的絕對增益為 1。

物理意義：Reference / correction 能有效通過 → 低通的通帶。
帶外 \(\omega \gg \omega_c\)

此時 \(|T(s)| \ll 1\)，reference-induced correction 無法再有效控制輸出，STF 迅速衰減，VCO 的自由振盪行為逐漸主導。

物理意義：Reference / correction 被抑制 → 低通的阻帶。
VCO 雜訊轉移函數 NTF(s)（高通特性）

雜訊直接加在輸出端，前向路徑不經任何增益：\(G_{\text{forward}}(s) = 1\)

\[ \text{NTF}_{\text{VCO}}(s) = \frac{\Phi_{\text{out}}}{\Phi_{\text{VCO,free}}}(s) = \frac{1}{1 + T(s)} \]
帶內 \(\omega \ll \omega_c\)

此時 \(|T(s)| \gg 1\)，因此 \(\text{NTF}_{VCO} \approx 1/T(s) \to 0\)。負回授能辨識並修正 VCO 的慢速相位擾動，所以 VCO 自身的近端相位雜訊被大幅壓制。

物理意義：VCO noise 被迴路壓制 → 高通的阻帶。
帶外 \(\omega \gg \omega_c\)

此時 \(|T(s)| \ll 1\)，因此 \(\text{NTF}_{VCO} \approx 1\)。迴路反應速度不足以修正快速的 VCO 相位擾動，VCO free-running noise 幾乎直接出現在輸出端。

物理意義：VCO noise 幾乎完全通過 → 高通的通帶。

3. CP-PLL 與 SSPLL 專屬迴路轉移函數與雜訊差異對比

傳統 CP-PLL 專屬推導 Divider in Feedback
回授除頻比：\(H(s) = \frac{1}{N}\)
鑑相增益：\(K_{\text{PD}} = \frac{I_{\text{CP}}}{2\pi}\text{ [A/rad]}\)
開迴路增益：\(T_{\text{CP}}(s) = \frac{I_{\text{CP}} K_{\text{VCO}} Z_{\text{LF}}(s)}{2\pi N \cdot s}\)
\[ \text{STF}_{\text{CP}}(s) = \frac{N \cdot T_{\text{CP}}(s)}{1 + T_{\text{CP}}(s)} \xrightarrow{\omega \ll \omega_c} \mathbf{N} \]

帶內相位尺度：Reference phase noise 經 \(\text{STF}_{CP}\approx N\) 傳至輸出，因此其 PSD 約增加 \(N^2\)（即 \(+20\log_{10}N\text{ dB}\)）。CP/PFD 雜訊若先 input-refer 成等效 phase noise，也可用相同 phase transfer；若直接從 CP current-noise PSD 出發，則必須使用其注入點專屬的 \(Z_{LF}K_{VCO}/[s(1+T)]\) 轉移函數，不能把 current noise 直接視為 reference phase noise。

次取樣 SSPLL 專屬推導 Core Loop (No Divider)
主鑑相迴路：直接取樣 RF；在正規化 sampled-phase 小訊號座標中可令 \(H_{SS}(s)=1\)
簡化等效鑑相/轉導增益：\(\beta_{\text{CP,SS}} \approx 2 A_{\text{VCO}} g_m \frac{\tau_{\text{pul}}}{T_{\text{ref}}}\)（一階模型）
開迴路增益：\(T_{\text{SS}}(s) = \frac{\beta_{\text{CP,SS}} K_{\text{VCO}} Z_{\text{LF}}(s)}{s}\)
\[ H_{\text{SS,norm}}(s) = \frac{T_{\text{SS}}(s)}{1 + T_{\text{SS}}(s)} \xrightarrow{\omega \ll \omega_c} \mathbf{1} \]
注意：此式是內部正規化 sampled-phase response；若定義 STF 為 absolute \(\Phi_{out}/\Phi_{ref}\)，reference timing jitter 映射到 RF phase 時仍需包含頻率倍增尺度 \(N\)。

SSPLL 的主要帶內優勢：主鑑相路徑不需以 \(1/N\) divider 將 VCO 先降頻，因此detector/SSCP 自身的等效輸入雜訊不承受傳統 CP-PLL 相同的 divider-related \(N^2\) penalty。常見一階近似可呈現 \(A_{VCO}\)、\(g_m\) 與 duty factor 對 detector noise 的改善趨勢，但實際係數取決於 sampler 波形斜率、sampling instant、switch noise、loading 與 SSCP 電路，應以 PSS/PNoise 校正。Reference source 本身的 timing jitter 並不因此免除 RF 頻率倍增的相位尺度。

兩架構共通與差異彙整
分析項目 傳統 CP-PLL 次取樣 SSPLL
二階濾波器阻抗 \(Z_{\text{LF}}(s)\) 完全共通：\(\frac{1+s R_1 C_1}{s (C_1+C_2)(1+s R_1 C_{\text{eq}})}\)
電阻 \(R_1\) 熱雜訊整形 完全共通：受開路零點與迴路反饋整形，輸出均為帶通特性 (Bandpass)
自由振盪 VCO 模型 完全共通：Leeson-type 漸近模型（\(-20\text{ dB/dec}\) 熱雜訊 + \(-30\text{ dB/dec}\) 閃爍雜訊）
主迴路除頻比 \(H(s)\) \(1 / N\) \(1\)（正規化 sampled-phase 核心迴路）
帶內 response Absolute \(\Phi_{out}/\Phi_{ref} \to N\) Internal normalized response \(\to1\)；absolute ref→RF phase 仍含 \(N\) 尺度
主要 \(N^2\) 關係 Reference phase：有；input-referred PFD/CP phase noise：有 Reference timing jitter：仍有 RF phase scaling；SSPD/SSCP detector noise：無 divider-related \(N^2\) penalty

4. 各子電路獨立雜訊物理模型 (Physical Noise Modeling)

A. 參考時脈 (Reference Clock)： Estimate 模式不假設特定晶振的絕對雜訊值，而由使用者輸入 far-out SSB phase-noise floor \(\mathcal L_{0,ref}\) 與 flicker corner \(f_{c,ref}\)。source PSD 採 white + flicker 的參數化形式；閉迴路 reference transfer 則由 PLL 相位域模型直接推導：
\[ \mathcal L_{\text{ref,src}}(f)=\mathcal L_{0,ref}\left(1+\frac{f_{c,ref}}{f}\right),\qquad H_{\text{ref}}(s)=N\frac{T(s)}{1+T(s)},\qquad \mathcal L_{\text{ref,out}}=\mathcal L_{\text{ref,src}}|H_{\text{ref}}|^2 \]
B. 鑑相器 / 電荷泵等效雜訊 (Detector / CP)： 本工具將 detector source 定義成輸入等效 phase-noise PSD，其 white floor 與 flicker corner 由使用者指定；因此 source 絕對值不是由網頁臆測，而是可由 transistor-level PNoise、量測或已知規格校正。CP-PLL 的 input-referred PFD/CP phase noise 經 absolute phase transfer 會包含 \(N^2\) scaling；SSPLL 則以 normalized sampled-phase detector coordinate 建立 continuous-time equivalent transfer。
\[ \mathcal{L}_{\text{det,out}}(f) \approx \mathcal{L}_{\text{det,eq}}(f)|H_{\text{det}}(j2\pi f)|^2, \quad H_{\text{det,CP}}=N\frac{T}{1+T},\; H_{\text{det,SS}}=\frac{T}{1+T} \]
Detector source model：\(\mathcal L_{det,eq}(f)=\mathcal L_{0,det}(1+f_{c,det}/f)\)。SSPLL 此處是 LTI continuous-time equivalent；精確 sampled/cyclostationary noise 應改用 Cadence PNoise contribution。
C. 濾波器阻尼電阻熱雜訊 (Resistor \(R_1\) Thermal Noise)： 電阻產生 one-sided Johnson voltage PSD \(S_{v,R1}=4k_BTR_1\,[\text{V}^2/\text{Hz}]\)。對目前「\(C_2\) 與 \(R_1\!+\!C_1\) 串聯支路並聯」的實際 loop-filter 拓樸，以節點方程可直接推得 \(R_1\) noise 到 \(V_{ctrl}\) 的精確 transfer，再經 VCO phase integrator 與 sensitivity function \(1/(1+T)\) 整形：
\[ S_{v_{ctrl},R_1}(f)=4k_BTR_1\,\frac{\left(\frac{C_1}{C_1+C_2}\right)^2}{1+\left(\omega R_1\frac{C_1C_2}{C_1+C_2}\right)^2} \] \[ \mathcal L_{R_1,out}(f)=\frac{1}{2}S_{v_{ctrl},R_1}(f)\left|\frac{K_{\text{VCO}}}{j\omega}\frac{1}{1+T(j\omega)}\right|^2,\qquad \omega=2\pi f \]
D. 壓控振盪器自由振盪 (Free-running VCO - Leeson-type Asymptotic Model)： 根據使用者設定的 \(1\text{ MHz}\) SSB phase-noise 錨點與 VCO flicker corner，建立 \(1/f^2\) 與 \(1/f^3\) 漸近斜率，再經 VCO sensitivity function 整形。模型特別以 \(1\text{ MHz}\) 處正規化，因此 free-running 曲線必定精確通過輸入錨點：
\[ \mathcal L_{\text{VCO,free}}(f)=10^{\mathcal L_{1M}/10}\left(\frac{1\text{ MHz}}{f}\right)^2\frac{1+f_{c,VCO}/f}{1+f_{c,VCO}/(1\text{ MHz})} \] \[ \mathcal L_{\text{VCO,out}}(f)=\mathcal L_{\text{VCO,free}}(f)\left|\frac{1}{1+T(j2\pi f)}\right|^2 \]
E. 回授除頻器自身雜訊 (Feedback Divider, CP-PLL only)： 對傳統 CP-PLL，除頻器除了透過 \(1/N\) 影響 loop gain，本身也可能產生 additive phase noise。此處將 \(\Phi_{n,div}\) 定義在除頻器輸出 / PFD feedback phase 座標，因此 error phase 為 \(\Phi_e=\Phi_{ref}-(\Phi_{out}/N+\Phi_{n,div})\)。由閉迴路方程可直接推得：
\[ H_{div\rightarrow out}(s)=\frac{\Phi_{out}}{\Phi_{n,div}}=-N\frac{T(s)}{1+T(s)} \] \[ \mathcal L_{div,out}(f)=\mathcal L_{div,src}(f)\,N^2\left|\frac{T}{1+T}\right|^2,\qquad \mathcal L_{div,src}(f)=\mathcal L_{0,div}\left(1+\frac{f_{c,div}}{f}\right) \]

負號代表 feedback injection 的相位方向，對 PSD 不影響。SSPLL 的主 sampling loop 沒有此 feedback divider，因此不把 Divider contribution 加進核心 SSPLL noise budget；若要分析輔助 FLL/計數器的鎖定期間雜訊，應建立另外的路徑模型，而不是套用此 CP-PLL transfer。

5. 帶內雜訊底、RMS 相位抖動與時間抖動詳細計算公式

A. 帶內相位雜訊底 (In-Band Phase Noise)

本工具將 \(10\text{ kHz}\) 作為一個固定的「代表性低 offset 取樣點」，直接回報該點所有已啟用 contribution 的線性功率總和。只有當 \(10\text{ kHz}\ll f_c\) 且 VCO/LPF contribution 已充分受抑制時，才可近似解讀為典型 in-band floor：

\[ \mathcal L_{\text{10k}}=10\log_{10}\!\left(\sum_{i\in\{ref,det,LPF,VCO,(Divider)\}}\mathcal L_{i,out,lin}(10\text{ kHz})\right)\quad[\text{dBc/Hz}] \]

B. RMS 相位抖動 (\(\sigma_\Phi\)) 的梯形積分法

單邊帶相噪轉換為雙邊折合之單邊相位功率譜密度 \(S_\Phi(f) = 2 \times 10^{\frac{\mathcal{L}_{\text{total}}(f)}{10}}\text{ [rad}^2/\text{Hz]}\)。程式在設定之區間 \([f_{\text{min}}, f_{\text{max}}]\) 內進行 \(M = 1000\) 點對數等間距採樣，透過梯形積分法則求總方差：

\[ \sigma_\Phi^2 = \int_{f_{\text{min}}}^{f_{\text{max}}} S_\Phi(f)\,df \approx \sum_{j=0}^{M-2} \frac{S_\Phi(f_j) + S_\Phi(f_{j+1})}{2} \cdot (f_{j+1} - f_j) \quad [\text{rad}^2] \]

RMS 相位誤差開根號取得：\(\sigma_\Phi = \sqrt{\sigma_\Phi^2}\text{ [rad]}\)，換算為角度：\(\sigma_{\Phi,\text{deg}} = \sigma_\Phi \times \frac{180^\circ}{\pi}\text{ [}^\circ\text{]}\)。

C. RMS 時間抖動 (\(\sigma_t\)) 的時域映射

時脈週期 \(T_0 = \frac{1}{f_{\text{VCO}}}\) 對應 \(2\pi\) 弧度相移。因此時間抖動由相位誤差直接縮放：

\[ \sigma_t = \frac{\sigma_\Phi}{2\pi \cdot f_{\text{VCO}}} \quad [\text{seconds}] \quad \xrightarrow{\times 10^{15}} \quad \sigma_t\text{ (fs)} \]

迴路轉移函數深度解析與直覺學習筆記 (Loop TF & Noise Intuition Guide)

建立「物理現象 → 訊號流模型 → 頻域代數求解」的完整架構直覺

Conceptual Notes

核心心法總結：為什麼 STF 是低通、NTF 是高通？

「閉迴路轉移函數」是所有路徑的統稱。它只有一個核心骨架：\(\frac{\text{前向增益 } G_{\text{forward}}}{1 + \text{環路增益 } T(s)}\)。由於低頻時迴路增益極大（\(|T| \gg 1\)）、高頻時增益衰減至消失（\(|T| \to 0\)），因此：

訊號轉移函數 STF (走全程) 低頻時迴路追隨輸入：\(STF \to N\) (通過)
高頻時濾波器衰減：\(STF \to 0\) (阻斷)
→ 標準低通濾波器特性
VCO 雜訊轉移函數 NTF (生在終點) 低頻時負回授全力消滅它：\(NTF \to 0\) (阻斷)
高頻時負回授失效管不到：\(NTF \to 1\) (洩漏)
→ 標準高通濾波器特性
單一負回授迴路的正規化互補關係：\[ H_{\text{track,norm}}(s)+H_{\text{VCO}}(s)=\frac{T(s)}{1+T(s)}+\frac{1}{1+T(s)}\equiv\mathbf{1} \]
CP-PLL 中 \(H_{\text{track,norm}}=\text{STF}_{CP}/N\)；SSPLL 中它對應正規化 sampled-phase tracking response，而非直接宣稱 absolute \(\Phi_{out}/\Phi_{ref}=1\)。

第一步：認識元件本體與它的「雙重身分」

VCO 的雙重身分

① 受控轉換機器（控制端 \(V_{\text{ctrl}}\)）：STF 的訊號走這條路。理想情況下將與控制電壓成線性正比的輸出頻率積分為相位，轉移增益為 \(\frac{K_{\text{VCO}}}{s}\)。

② 自發物理擾動發電機（諧振腔內部）：即使將控制電壓定死（接理想乾電池），內部的電晶體溝道熱雜訊與閃爍雜訊仍在撞擊震盪核心，無中生有產生隨機抖動 \(\Phi_{\text{VCO,noise}}\)。這就是為什麼不能只看控制端，必須單獨替它推導 NTF！

PFD / CP 與 LPF 阻尼電阻

PFD/CP：將相位差轉為電流。但開關切換時電晶體失配會產生電流噪聲 \(I_{n,\text{CP}}\)，注入在濾波器輸入端。

阻尼電阻 \(R_1\)：為了提供零點補償穩定迴路而串聯，但它本身產生 \(4k_B T R_1\) 熱雜訊，在迴路中形成獨特的帶通（Bandpass）拱形凸起。

第二步：大一統節點訊號流方程與代數推導

我們不需要為 STF 和 NTF 各自套用兩套公式。只要把輸出相位視為「前級控制訊號」與「VCO 內部自發雜訊」的疊加，即可寫出單一節點方程：

\[ \Phi_{\text{out}}(s) = \underbrace{\left[ K_{\text{PD}}\left(\Phi_{\text{in}}(s) - \frac{\Phi_{\text{out}}(s)}{N}\right) + I_{n,\text{CP}}(s) \right] Z_{\text{LF}}(s) \frac{K_{\text{VCO}}}{s}}_{\text{受前級控制的正常前向路徑訊號}} + \underbrace{\Phi_{\text{VCO,noise}}(s)}_{\text{VCO 內部自發雜訊}} \]

定義環路一整圈的增益 \(T(s) = \frac{K_{\text{PD}} Z_{\text{LF}}(s) K_{\text{VCO}}}{s \cdot N}\)，將所有含 \(\Phi_{\text{out}}(s)\) 的項移到左邊：

\[ \Phi_{\text{out}}(s) \cdot [1 + T(s)] = \Phi_{\text{in}}(s) \cdot N \cdot T(s) + I_{n,\text{CP}}(s) \cdot \frac{Z_{\text{LF}}K_{\text{VCO}}}{s} + \Phi_{\text{VCO,noise}}(s) \]

兩邊同除以 \([1 + T(s)]\)，STF 與 NTF 便在同一條式子中同時解出：

\[ \Phi_{\text{out}}(s) = \underbrace{\left[\frac{N \cdot T(s)}{1 + T(s)}\right]}_{\mathbf{STF}(s)} \cdot \Phi_{\text{in}}(s) + \underbrace{\left[\frac{\frac{Z_{\text{LF}}K_{\text{VCO}}}{s}}{1 + T(s)}\right]}_{\mathbf{NTF}_{\text{CP}}(s)} \cdot I_{n,\text{CP}}(s) + \underbrace{\left[\frac{1}{1 + T(s)}\right]}_{\mathbf{NTF}_{\text{VCO}}(s)} \cdot \Phi_{\text{VCO,noise}}(s) \]

第三步：全面理解的三大互補視角

視角 1：代數拓撲觀

在單一負回授架構中，分母 \(1 + T(s)\) 是整套閉環系統的公共特徵，不管誰的雜訊分母都一樣。分子則嚴格由「注入節點到輸出端的前向增益路徑」決定。

視角 2：時域物理觀

慢速變化（低頻）：迴路反應完全跟得上，PFD 與電容立刻反向拉回 VCO 偏差，雜訊被抵消；快速抖動（高頻）：突波早就傳出去了，負回授反應不及，VCO 雜訊完全洩漏。

視角 3：頻率權衡觀

頻寬 \(f_c\) 是一場拔河遊戲：\(f_c\) 太小，壓不住糟糕的 VCO 雜訊；\(f_c\) 太大，輸入端與 CP 雜訊（乘上 \(N^2\)）全灌進來。交越點就是總 RMS Jitter 的最佳解。

第四步：次取樣 SSPLL 與傳統 CP-PLL 為什麼在帶內相差巨大？

在理解了大一統方程後，SSPLL 的優勢一目了然：

傳統 CP-PLL：除頻器在迴路內
回授路徑：\(H(s) = 1/N\)
帶內訊號增益：\(\text{STF}(0) = N\)
Reference phase noise 與 input-referred PFD/CP phase noise 在 RF 輸出端呈現 \(N^2\) PSD scaling；直接以 CP current-noise 分析時則須使用其專屬 injection-point transfer。
次取樣 SSPLL：主迴路無除頻器
回授路徑：RF 直接取樣，\(H(s) = 1\)
正規化 sampled-phase tracking：\(H_{\text{SS,norm}}(0) \approx 1\)
SSPD/SSCP detector noise 不承受 divider-related \(N^2\) penalty；但 reference source timing jitter 映射到 RF output phase 時仍具有頻率倍增尺度。\(g_m\) 是重要參數之一，不是唯一決定因子。

1. 交越頻寬 fc (Unity Gain Crossover)

開迴路增益 \(|G(j\omega_c)| = 1\) (即 0 dB) 之頻率，決定了閉迴路追隨與暫態建立速度。通常需滿足 \(f_c \le \frac{f_{\text{ref}}}{10} \sim \frac{f_{\text{ref}}}{20}\) 之穩定限制。

2. 相位裕度 Phase Margin (PM)

\(\text{PM} = 180^\circ + \angle G(j\omega_c)\)。表示在 0 dB 增益交越處，系統相位距離 \(-180^\circ\) 臨界振盪點的安全餘裕。最佳目標通常設在 60°（阻尼比 \(\zeta \approx 0.707\)）。

3. 零點 fzero 超前補償

由 \(R_1, C_1\) 產生 (\(f_{\text{zero}} = \frac{1}{2\pi R_1 C_1}\))，在 \(f_c\) 前提供 +45°/dec 相位超前，以拉回雙重積分帶來的 -180° 相移。

4. 極點 fpole 紋波抑制

由 \(C_2\) 形成 (\(f_{\text{pole}} = \frac{C_1+C_2}{2\pi R_1 C_1 C_2}\))，可大幅濾除切換開關造成的瞬間脈衝與高頻雜散，建議配置 \(f_{\text{pole}} \ge 5 f_c\)。

5. 次取樣電荷泵跨導 \(g_m\) 與雜訊抑制原理 (SSCP Transconductance)

在次取樣 PLL (SSPLL) 中，SSPD 取樣的高頻 VCO 電壓誤差 \(\Delta V_{sam}\) 經由 SSCP 跨導級（MOS 差動對）轉換為電流。

\(g_m = \frac{2 I_{CP}}{V_{gs,eff}} = \frac{2 I_{CP}}{V_{GS} - V_{TH}} = \sqrt{2 \mu C_{ox} \frac{W}{L} I_{CP}}\)
其中 \(I_{CP}\) 為差動對分支偏壓電流，\(V_{gs,eff}\) 為電晶體超驅電壓（通常設計在 0.15V ~ 0.25V）。
\(\beta_{\text{CP,SS}} = 2\cdot A_{\text{VCO}} \cdot g_m \cdot \frac{\tau_{\text{pul}}}{T_{\text{ref}}}\)
SSPLL 的 detector/SSCP 路徑不承受傳統 divider-related \(N^2\) penalty；在本一階模型中，提高 \(A_{VCO}\) 或 \(g_m\) 可降低等效 detector noise，但實際改善量仍取決於 sampler slope、switch thermal/flicker noise、loading 與 bias，需用 PNoise 驗證。
